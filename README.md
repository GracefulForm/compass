# Princeton, TX Compass & Orienteering Course

A compass / orienteering course in the J.M. Caldwell Sr. Community Park in Princeton, TX.

* The QR code on the sign at the park goes to this repository. View the mobile-first website [here](https://gracefulform.github.io/compass/index.html).
* Please use the GitHub Issues menu to report errors.

### Scouting
This project is the 2026 Eagle Scout Service Project of Jacob Bailey. [Visit Be A Scout](https://beascout.org) for more information on Scouting.
